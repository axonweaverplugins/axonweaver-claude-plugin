# Плагин AxonWeaver для Claude Code

Агент команды узнаёт платформу AxonWeaver от самой платформы. При каждом старте сессии плагин берёт
`GET https://admin.axonweaver.ai/api/agent/bootstrap` с личным ключом агента и получает:

- руководство, собранное по ролям этого ключа (суперадмин, BD, аналитик, QA, техлид, DevOps…);
- MCP-серверы этих ролей (адреса и откуда взять доступ — без ключей);
- навыки рабочих мест платформы.

В сессию сразу попадает короткая часть (правила и серверы), полное руководство ложится в данные плагина — агент
читает его перед первой задачей. Поменяли раздел руководства на платформе — после выкатки его получат все агенты.

## Установка

В сессии Claude Code:

```
/plugin install axonweaver --marketplace axonweaverplugins/axonweaver-claude-plugin
```

Ответь `y` на добавление каталога, выбери область (user).

**Вход своей учётной записью (советуем).** Поля ключей при установке оставь пустыми и набери `/axonweaver:login`:
плагин покажет ссылку и код — открой ссылку, войди своей учётной записью AxonWeaver (Keycloak), подтверди код и начни
новую сессию. Платформа узнаёт тебя и твои роли; выход — `/axonweaver:logout`, отзыв доступа — в Keycloak. Пока так
входят суперадмины и администраторы realm.

**Или ключами** от владельца платформы — плагин спросит:

| Поле | Что это |
|---|---|
| Личный ключ агента | `X-Axon-Key`: по нему платформа узнаёт тебя и твою роль. Выдаёт владелец платформы |
| Служебный ключ MCP | Bearer MCP-сервера платформы. Выдаёт владелец платформы |
| Адрес платформы | по умолчанию `https://admin.axonweaver.ai` |

Ключи хранятся в защищённом хранилище Claude Code, в файлы не пишутся. Поменять:
`/plugin configure axonweaver@axonweaver`.

Нужен `python3` (на macOS есть с Xcode Command Line Tools).

## Что внутри

| Часть | Что делает |
|---|---|
| `hooks/hooks.json` + `bin/axon_bootstrap.py` | при старте, возобновлении, `/clear` и сжатии сессии берёт руководство с платформы; если платформа недоступна — последнее полученное, с пометкой |
| `.mcp.json` | MCP-сервер платформы `axonweaver` (все рабочие места): твой личный токен Keycloak (обновляется сам, `bin/axon_auth.py headers`) или ключи |
| `/axonweaver:status` | кто ты для платформы, роли, версия руководства, MCP-серверы ролей |
| `/axonweaver:refresh` | перечитать руководство посреди сессии (MCP-инструмент `agent_guide`) |
| `/axonweaver:login`, `/axonweaver:logout` | войти агентом своей учётной записью Keycloak (вход по коду) и выйти |
| `skills/axonweaver-basics` | базовые правила на случай, когда платформа недоступна |

Другие MCP-серверы (Axon Risk, аналитика, FlutterFlow) плагин не подключает сам — у каждого свой доступ; их адреса
и откуда взять доступ агент видит в руководстве своей роли.

## Данные

Ключ агента и токены уходят только на адрес платформы и в Keycloak. В `~/.claude/axonweaver` (папка 700, файлы 600)
лежат последнее руководство, его версия и — при входе через Keycloak — токен обновления; токены не печатаются.
